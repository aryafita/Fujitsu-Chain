# Fujitsu L1

Fujitsu is a custom Layer 1 blockchain built on the Canopy Network protocol, designed as a lightweight transfer and reward distribution chain for Web3 communities.

## Token
- **Name:** Fujitsu Token
- **Ticker:** FUJI
- **Use case:** Peer-to-peer token transfers with on-chain reward distribution

## Features
- Fast finality via Canopy BFT consensus
- Custom reward transaction type for community incentives
- Minimal fee structure for micro-transactions

## Built with
Canopy Plugin Template (Go) — https://github.com/canopy-network/canopy
